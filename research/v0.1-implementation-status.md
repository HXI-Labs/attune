# v0.1 implementation status

## Outcome

The public-data technical v0.1 pipeline is implemented, but release is paused
after a live false-positive failure. The result is a locally runnable,
calibrated, time-aligned
SenseVoice derivative with FP and mixed-INT8 ONNX graphs, batch and
pseudo-streaming APIs, schema-v2 JSON, deterministic XML, reproducible
manifests, and hashed evaluation artifacts. It is now on an
accuracy-hardening branch with a mandatory manual hostile-speech regression
gate.

This is not the entire original research programme: no downstream human study,
naturalistic multi-rater affect collection, reviewed V/A/D training source, or
public-weight release has been completed. No claim is made for those items.

## ASR corrective architecture

The initial sealed single-tail model passed every perception and INT8 parity
gate but degraded WER by 0.0223 absolute versus the frozen base. The release was
stopped rather than lowering the gate.

The final model adds frozen copies of only the base encoder's last two blocks
and final norms for CTC ASR. The lower encoder and frozen temporal-predictor
blocks remain shared; the adapted path remains unchanged for perception. This
adds 6,318,080 parameters, producing a 241,609,098-parameter model. On
development it restores frozen-base WER exactly (0.1110) while leaving every
perception metric unchanged.

Because this correction followed inspection of the initial sealed WER, the
corrected ASR score must be externally reconfirmed. Perception selection and
calibration were not changed.

## Honest remaining work

The model/deployment implementation exists, but the release deliverable is not
done. Required evidence stages are:

1. Re-run the original hostile-speech recording and confirm no unsupported
   event or style output.
2. Collect a naturalistic, multi-rater English corpus including Ghanaian and
   British English and reviewed V/A/D labels.
3. Confirm corrected ASR on a new untouched external set.
4. Run the preregistered downstream conversational human study.
5. Benchmark GPU/Linux/other Apple hardware and longer production-like streams.
6. Complete final legal review before redistributing weights or audio.
